# CartShare - Collaborative Shopping Ecosystem

A real-time collaborative shopping cart web application built for shared living environments (like student dorms, office teams, or travel groups) to coordinate joint purchases seamlessly.

## 🚀 Features Implemented
* **User Access & Room Management:** Secure entry using HTML forms and JavaScript where users can log in with their name and join or create a unique "Room" using a shared code.
* **Shared Cart & Real-Time Sync:** Add and remove items from a shared cart that synchronizes across browser tabs/sessions using LocalStorage and event listeners.
* **Activity Log Feed:** A live activity log tracking all participant actions in the room.
* **Audit-Ready Printable Receipts:** Clean printable summary generated using CSS print media rules and JavaScript.
* **Responsive UI:** Modern design built with HTML5, CSS Flexbox, Grid, and Bootstrap 5 to work perfectly on both mobile phones and PCs.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Bootstrap 5, Bootstrap Icons
* **Logic & State Management:** Vanilla JavaScript, Browser LocalStorage, BroadcastChannel API
